# Sistema de Seguridad Inteligente - La Matanza

## Resumen
Este proyecto propone un sistema de seguridad inteligente para el partido de La Matanza que utiliza vision por computadora para detectar situaciones de riesgo y enviar alertas en tiempo real por WhatsApp.

## Summary
This project proposes an intelligent security system for La Matanza district that uses computer vision to detect risk situations and send real-time alerts via WhatsApp.

## El problema
Falta de monitoreo en tiempo real en barrios de La Matanza y demora en la respuesta ante incidentes.

## Mi solucion con IA
Usar vision por computadora para analizar camaras y detectar eventos, con alertas automaticas.

## Datos
Videos anonimizados de camaras y reportes de vecinos sin datos personales.
