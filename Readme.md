# TutorIA - Asistente para estudiantes

## Idea
Un asistente que ayuda a estudiantes de secundaria a entender tareas y explicar paso a paso.

## Problema
Los estudiantes se traban con tareas y no tienen quien les explique simple.

## Solucion
Una IA que explica con ejemplos simples, adaptada para Argentina.

## Para quien es
Estudiantes de 13 a 18 años.

## Como funciona
1. Escribe tu duda
2. La IA explica paso a paso
3. Da ejemplos faciles
